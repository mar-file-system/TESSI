Still struggling so now I was finally able to install a VM using CentOS 8 Stream
http://mirror.centos.org/centos/8-stream/BaseOS/x86_64/os/

Now I'm going to snapshot it:
sudo virsh snapshot-create-as --domain tassi01 centos8streamsnap --description "CentOS 8 Stream Snapshot"

sudo virsh snapshot-list tassi01

# to restart it
sudo virsh snapshot-revert tassi01 centos8streamsnap
sudo virsh start tassi01
