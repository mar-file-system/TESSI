Howto setup a lustre test environment on a Macbook Pro.  Upon completion of
these steps you will have a single virtual machine running a Lustre MGS,
MDS, and OSS.  It is beneficial to enter those names into /etc/hosts for 
easy access from your local laptop:  

  192.168.56.11  knotfs-lustre knotfs-mgs1 knotfs-mds1 knotfs-oss1

--

These instructions use Lustre 2.8 because the VM guest OS is CentOS 7, and Lustre 2.8 is the 
first version of Lustre that supports Lustre 2.8.

1.  Setup Virtualization

    1.1 Install virtualbox and create the host-only network
        Create vboxnet0 with 192.168.1.0 range
        Begin DHCP at 192.168.1.200
        
    1.2 Download Centos 7 minimal ISO
    
    1.3 Install Image with the following settings
        Ram: 2GB
        Disk: 6GB dynamic
        CD: Centos iso
        Networking 1: host-only
        Host-only Name: vboxnet0
        Networking 2: nat
        Devices->Clipboard->bidirectional
        Add 2 disks to SATA controller:
		knotfs-mgt1 (1GB)
		knotfs-mdt1 (2GB)
		knotfs-ost1 (2GB)
        Go through the prompted steps for install
        
    1.4 Post-install setup
        Ensure /etc/sysconfig/network-scripts/ifcfg-enp0s3 contains:
          BOOTPROTO=none
          ONBOOT=yes
	  IPADDR=192.168.1.11
	  PREFIX=24

        Ensure /etc/sysconfig/network-scripts/ifcfg-enp0s8 contains:
	  BOOTPROTO=dhcp
          ONBOOT=yes

	Disable SELinux (/etc/selinux/config):
	  SELINUX=disabled

        Set the hostname
          hostnamectl set-hostname knotfs-lustre

        Edit /etc/hosts
            192.168.1.11  knotfs-mgs1 knotfs-mds1 knotfs-oss1
            192.168.1.101 knotfs-client1
	
	Disable kernel and lustre updates:
	  echo 'disable=kern*,lustre*,zfs*' >>/etc/yum.conf

    1.5 Update software and install tools
	yum update
	yum install -y net-tools wget

        
    1.6 Retrieve Lustre 2.8 RPMs
	mkdir ~/Downloads
	wget -r -A *.rpm http://downloads.hpdd.intel.com/public/lustre/latest-maintenance-release/el7/server/RPMS/x86_64/
	mv downloads.hpdd.intel.com/public/lustre/latest-maintenance-release/el7/server/RPMS/x86_64/*rpm Downloads

    1.7 Install Lustre compliant kernel and REBOOT
	cd ~/Downloads
	yum install perl
	rpm -Uhv --oldpackage Downloads/kernel*.rpm

    1.8 Reboot.  You must switch to the new, Lustre-compatible kernel for the remaining steps
	shutdown -r now
	Login
	uname -r

    1.9 Install Lustre Prerequisites
	yum install epel-release man man-pages ncurses-devel
        yum localinstall --nogpgcheck \
            http://archive.zfsonlinux.org/epel/zfs-release.el7.noarch.rpm

    1.10 Install Lustre
	cd ~/Downloads
	yum install zfs-0.6.4.2 lustre-osd-zfs*.rpm
	yum install lustre-2*rpm lustre-dkms*rpm lustre-debuginfo*rpm lustre-iokit*rpm lustre-modules*rpm 
    
2.  Create the Lustre Storage for MGS, MDS, and OSS

    2.1 Create required ZPools
	modprobe zfs
      	zpool create -f -o ashift=12 -O compression=lz4 mgt /dev/sdb
      	zpool create -f -o ashift=12 -O compression=lz4 mdt /dev/sdc
      	zpool create -f -o ashift=12 -O compression=lz4 ost /dev/sdd
      	zpool list
      
    2.2 Create on-disk formats
        mkfs.lustre --mgs --backfstype=zfs --device-size=131072 mgt/mgt1
        mkfs.lustre --mdt --backfstype=zfs --device-size 131072 --index=0 --mgsnode=192.168.56.11@tcp --fsname=knotfs mdt/mdt1
        mkfs.lustre --ost --backfstype=zfs --device-size=131072 --index=0 --mgsnode=192.168.56.11@tcp --fsname=knotfs ost/ost1
        zfs list

    2.3 Configure the file system
	echo "" > /etc/modprobe.d/lnet.conf
	echo "" > /etc/modprobe.d/lustre.conf
	echo "" > /etc/modprobe.d/lnet.conf
	echo 'options lnet networks=tcp0(enp0s3)' >> /etc/modprobe.d/lustre.conf

    2.4 Start the file system
	mount -t lustre /mnt/mgt mgt/mgt1
	mount -t lustre /mnt/mdt mdt/mdt1
	mount -t lustre /mnt/ost ost/ost1
          
3.  Mount the file system as a client

    3.1 Mount the file system
	mkdir /mnt/knotfs
	mount -t lustre knotfs-lustre@tcp:/knotfs /mnt/knotfs
	chmod 777 /mnt/knotfs

    3.2 Test the mount
        dd if=/dev/zero of=/mnt/knotfs/tmp1 bs=4M count=20
        ls -l /mnt/knotfs
        cat /mnt/knotfs/tmp1

    3.3 Congratulations!
