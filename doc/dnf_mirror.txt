I'm trying to access the NFS mount /mnt/usrc-storage-nfs from within a VM. 
But trying to mount it from within the VM has failed. 
So now I'm trying to access the host's mount from within the guest. 
Apparently this requires /usr/libexec/virtiofsd and making changes to the VM's XML to use shared memory and a NUMA CPU. 
To get shared memory, I might need huge pages and a huge page allocation so I did this:
echo "vm.nr_hugepages=256" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
OK. This didn't work because libvirt complains about:
[jbent@in16 ~]$ sudo virsh define dnfmirror.xml
error: Failed to define domain from dnfmirror.xml
error: unsupported configuration: virtiofs requires shared memory
I tried using type=libvirt and type=9p but neither were recognized. 

So now I'm going to try to get the host to re-export the NFS share. To do so, I modified the line in /etc/fstab:
10.15.1.11:/mnt/vol0/usrc-storage /mnt/usrc-storage-nfs nfs nfsvers=3,noatime,intr,nosuid,nohide,crossmnt 0 0
OK, those options aren't supported. So now I'm just going to try to export it without those options:
On the host:
    sudo systemctl start nfs-server
    sudo systemctl enable nfs-server
    edit /etc/exports to add:
    /mnt/usrc-storage-nfs {guest_ip}/24(rw,sync,no_root_squash,no_subtree_check,fsid=202)
    sudo exportfs -r


Then in the guest VM, mount it like this:
sudo mount -t nfs <host_ip>:/mnt/usrc-storage-nfs /mnt-usrc-storage
In this case, the <host_ip> is 192.168.122.1.
