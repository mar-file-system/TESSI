We are pleased to announce that the Lustre 2.15.0 Release has been declared GA and is available for download<https://downloads.whamcloud.com/public/lustre/lustre-2.15.0/> <https://downloads.hpdd.intel.com/public/lustre/lustre-2.11.0/> . You can also grab the source from git<https://git.whamcloud.com/?p=fs/lustre-release.git;a=commit;h=745580a141965fb8d4d3ad5611d98b9e72c350b6>

This major release includes new features:

Client Directory Encryption A mechanism leveraging fscrypt has been introduced to allow file names to be encrypted on the client before network transfer and persistent OST and MDT storage (LU-13717<https://jira.whamcloud.com/browse/LU-13717>)

Network Selection Policy (UDSP) Allows creation of policies about which network interfaces to use under given circumstances (LU-9121<https://jira.whamcloud.com/browse/LU-9121>)

Fuller details about this release can be found in the 2.15 wiki page <http://wiki.lustre.org/Release_2.15.0> (including the change log <http://wiki.lustre.org/Lustre_2.14.0_Changelog> and test matrix<https://wiki.lustre.org/Release_2.15.0#Test_Matrix>)

Lustre 2.15.x will be the new LTS stream and a 2.15.1 release will be issued shortly to provide support for recent Linux distributions.

Please log any issues found in the issue tracking system<https://jira.whamcloud.com/>

Thanks to all those who have contributed to the creation of this release.
