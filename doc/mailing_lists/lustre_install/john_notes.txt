For easier host-resolution:
> sudo dnf install libvirt-nss
Edit /etc/nsswitch.conf to change the hosts: line to add libvirt libvirt_guest
Test with getent hosts [domain_name]

Then the default location for /var/lib/libvirt is in a small disk partition. So do this:
> sudo mkdir /home/libvirt
> sudo mv /var/lib/libvirt/images /home/libvirt
> sudo ln -s /home/libvirt/images/ /var/lib/libvirt/
